# GitHub Actions Assignment

Six GitHub Actions workflows demonstrating workflow_dispatch inputs, job outputs, matrices, caching, artifacts, debugging, composite actions, and reusable workflows.

## Workflows
- Q1: release notes with inputs and job outputs
- Q2: matrix build with cache and artifacts
- Q3: fixed trigger/runner/checkout workflow
- Q4: conditional deployment debugging
- Q5: job outputs and needs debugging
- Q6: composite action + reusable workflow

No real deployment or secrets are used.
